GitHub Pages での無料公開手順

このWebアプリはHTML・CSS・JavaScriptの3ファイル構成です。3ファイルを同じフォルダ構成でGitHubリポジトリに配置すれば公開できます。

  1. GitHub で新規リポジトリ（例: pdf-word-editor）を作成します。
  2. word_pdf_github_pages.html、css/app.css、js/app.js を配置します（トップページとして公開する場合はHTMLを index.html にする必要があります）。
  3. リポジトリの Settings → Pages を開きます。
  4. Branch を main（または master）の / (root) に設定して Save を押します。
  5. 数十秒待つと、https://あなたのID.github.io/pdf-word-editor/ で世界中どこからでも使えるPDF編集Webアプリとして公開されます！
セキュリティとプライバシー設計:
PDFファイルの読み込み・解析・編集・出力はブラウザ内で行い、PDF本文をアプリのサーバーへ送信しません。ただし、PDF.js等のライブラリ、フォント、CSSフレームワークは外部CDNから読み込まれます。機密文書を扱う場合は、CDN依存を自己ホスト化した構成を推奨します。
